### Added:
- A new tab in the integrated browser now opens with the address bar focused and empty, ready to type into
- F6 focuses the address bar, with the address selected so typing replaces it
- Double-clicking the empty space after the tabs opens a new tab, on the top strip and below the vertical tabs list

### Fixed:
- Addresses typed in the integrated browser that redirect to another site, like `google.pt` sending you on to `google.com`, now open in the tab. Before, they flashed a new tab that closed itself and the page never changed. Reloading, going back or forward, and submitting a form get the same fix when they redirect elsewhere
